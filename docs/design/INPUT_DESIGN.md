# インプット設計

最終更新: 2026-04-12

---

## 概要

KakeMieru へのデータ入力に関する設計。

---

## データの入力経路

| 経路 | フェーズ | ステータス | 詳細 |
|---|---|---|---|
| CSV 取り込み（Web アップロード） | フェーズ1 | 設計済み | `/imports/new`（CSV タブ） |
| 手動まとめ入力 | フェーズ1 | 設計済み | `/imports/new`（手動まとめタブ）。複数件をテーブル形式で一括入力 |
| 手動1件入力 | フェーズ1 | 設計済み | `/transactions/new`。現金・QR など CSV に載らない支出 |
| CLI コマンド（`rails import:run`） | フェーズ4 | 保留 | ローカルからバッチ取り込み |
| フォルダウォッチャー（常駐プロセス） | フェーズ4 | 保留 | 指定フォルダを監視して自動取り込み |

詳細な画面・フローは [SCREEN_DESIGN.md](SCREEN_DESIGN.md) を参照。

## CSV フォーマット対応

詳細は [decisions/0012-csv-import-strategy.md](../decisions/0012-csv-import-strategy.md) を参照。

| フェーズ | 内容 |
|---|---|
| フェーズ1 | **楽天カード** 決め打ちパーサー |
| フェーズ2 | ヘッダー自動検出（列名キーワードマッチ）で複数社対応 |
| 将来 | ヘッダーなし CSV のデータ形式から自動推定 |

### 楽天カード CSV の前処理（フェーズ1）

| 項目 | 対応内容 |
|---|---|
| 文字コード | Shift-JIS → UTF-8（`CSV.read(path, encoding: "Shift_JIS:UTF-8")`） |
| BOM 付き UTF-8 | 楽天カードは非該当。フェーズ2以降で対応 |
| 先頭の説明行スキップ | ヘッダー行（「利用日」を含む行）を検出するまでスキップ |
| 金額のカンマ除去 | `"1,200".delete(",").to_i` |
| 日付フォーマット | `YYYY/MM/DD` → `Date.parse`（`2026/01/15` → `2026-01-15`） |
| 使わない列 | 利用者・支払方法・支払手数料・支払総額は無視 |

## 重複取り込み防止

| ケース | 対応 |
|---|---|
| 同一ファイル（SHA256 ハッシュ一致）の2回目アップロード | エラーでブロック。「2026-01-07 に同じファイルを取り込み済みです」+ 取り込み履歴リンクを表示 |
| 同日 + 同金額 + 同店舗の明細 | フェーズ1では未対応（許容する）。フェーズ2で警告+確認を実装 |

## 取り込み後のデータ管理

| 項目 | ステータス | 詳細 |
|---|---|---|
| 未分類明細の手動カテゴリ修正 | 設計済み | 明細一覧のセレクトで即時変更（Turbo Stream）。詳細は [SCREEN_DESIGN.md](SCREEN_DESIGN.md) |
| 明細の編集（金額・日付訂正） | 設計済み | `/transactions/:id/edit`。`amount_override` / `date_override` に訂正値を保存 |
| 明細の削除 | 設計済み | `deleted_at` によるソフトデリート（Turbo Stream） |
| 取り込みまとめ取り消し | 設計済み | `/imports/:id/cancel_confirm` で全件ソフトデリート。Import レコードは残す |
| 取り込み履歴 | 設計済み | `/imports` で一覧表示 |

---

## 支払方法管理

| 項目 | ステータス | 詳細 |
|---|---|---|
| 複数支払方法の管理 | 設計済み | `payment_methods` テーブル。credit / debit / e_money / qr / cash |
| ユーザー登録時の初期生成 | 設計済み | 「現金」（payment_type: cash）を1件自動生成 |
| デビットカード・銀行口座 | フェーズ1対象外 | フェーズ2以降で対応 |
