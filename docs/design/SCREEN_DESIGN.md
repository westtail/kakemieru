# 画面設計

最終更新: 2026-04-11

---

## 技術方針

| 操作 | 実装方法 | 理由 |
|---|---|---|
| カテゴリ変更・明細削除・金額訂正 | Turbo Stream | JS不要・部分更新 |
| フォーム送信・ページ遷移 | Turbo Drive | 通常の Rails フォーム |
| 手動まとめ入力の行追加 | Stimulus | DOM 操作が必要な最小限の JS |
| グラフ描画・月切り替え | Stimulus + fetch + Chart.js | JSON を受け取って再描画 |

**基本方針**: Turbo Stream でページ遷移なしの部分更新を実現。JS は Stimulus + グラフのみに限定。

## 「取り込む」ボタンの配置

取り込み操作は `/imports/new` に集約するが、複数箇所からアクセスできる。

```
ダッシュボード   → [CSV取り込み] ボタン    → /imports/new（CSV タブ）
明細一覧         → [CSV取り込み] ボタン    → /imports/new（CSV タブ）。データがない月は特に目立つ
グローバルナビ   → [+ 取り込み ▼] ドロップダウン（常設）
```

### グローバルナビ [+ 取り込み] ドロップダウン

```
[+ 取り込み ▼]
├─ CSV 取り込み       → /imports/new（CSV タブ）
├─ 手動まとめ入力     → /imports/new（手動まとめタブ）
└─ 手動1件入力        → /transactions/new
```

- Turbo Drive によるページ遷移（JS 不要）
- `#csv` / `#manual_bulk` フラグメントでタブを初期選択

## 入力経路

```
① CSV 取り込み（/imports/new）
   ファイル選択 → 支払方法選択 → 確認 → Import（source_type: csv）+ Transaction N件

② 手動まとめ入力（/imports/new）
   支払方法選択 → テーブル形式で複数件入力 → Import（source_type: manual_bulk）+ Transaction N件

③ 手動1件入力（/transactions/new）
   日付・金額・店舗名・支払方法・カテゴリ → Transaction 1件（import_id = NULL）
```

## ダッシュボード（/）

当月の収支サマリー。月切り替えで過去月も参照可能。

```
┌─────────────────────────────────────┐
│  ← 2026年3月   2026年4月   2026年5月 →  │← 月切り替え（Stimulus + fetch）
├─────────────────────────────────────┤
│  2026年4月の支出                     │
│  ¥128,400                           │
│                                     │
│  [カテゴリ別円グラフ]                 │← Stimulus + Chart.js
│                                     │
│  未分類 3件 ⚠️  → /transactions     │← クリックで /transactions?category=uncategorized へ遷移（未分類フィルタ適用済み）
│                                     │
│  [CSV 取り込み]  [手動入力]           │
└─────────────────────────────────────┘
```

- デフォルト: 当月（アクセス時点の年月）
- 月切り替えは Stimulus + fetch でグラフと合計額のみ再描画（ページ遷移なし）
- グラフデータは `GET /transactions/summary?month=2026-04` → JSON で取得
- URL は `/?month=2026-03` の形式でブックマーク可能（Turbo Drive で更新）

## 取り込み画面（/imports/new）

CSV 取り込みと手動まとめ入力をタブで切り替え。

### タブ1: CSV 取り込み

```
┌─────────────────────────────────────┐
│  [CSV 取り込み] [手動まとめ入力]      │
├─────────────────────────────────────┤
│  支払方法  [楽天カード ▼]            │
│  ファイル  [ファイルを選択]           │
│                                     │
│  ※同じファイルは取り込めません        │
│                                     │
│  [取り込む]                          │
└─────────────────────────────────────┘
```

**取り込み完了後のフロー**
```
成功: → /transactions（取り込んだ明細の月）へリダイレクト
      + フラッシュ「楽天カードの 47 件を取り込みました」
失敗: → /imports/new に留まりエラー表示（再試行可能）
```

### タブ2: 手動まとめ入力

```
┌─────────────────────────────────────┐
│  [CSV 取り込み] [手動まとめ入力]      │
├─────────────────────────────────────┤
│  デフォルト支払方法  [現金 ▼]        │← 全行の初期値。行ごとに変更可
│                                     │
│  日付    店舗名      金額  カテゴリ  支払方法    │
│  [4/08] [ローソン ] [500] [食費▼] [現金▼]    │
│  [4/09] [松屋     ] [900] [食費▼] [PayPay▼] │← 行ごとに変更可
│  [4/10] [         ] [   ] [  ▼ ] [現金▼]    │
│  [+ 行を追加]                ← Stimulus      │
│                                              │
│  [保存]                                      │
└──────────────────────────────────────────────┘
```

- デフォルト支払方法を変更すると、未入力行の支払方法が自動更新される（Stimulus）
- 既に手動で変更した行はデフォルト変更の影響を受けない
**保存完了後のフロー**
```
成功: → /transactions（入力した明細の月）へリダイレクト
      + フラッシュ「3 件を保存しました」
失敗: → /imports/new に留まりエラー行をハイライト表示
```

## 明細一覧（/transactions）

### 絞り込みバー

| 項目 | 内容 |
|---|---|
| 月 | 年月セレクト（デフォルト: 当月） |
| 支払方法 | セレクトボックス |
| カテゴリ | セレクトボックス（「未分類」を含む。ダッシュボードバッジからは未分類が選択済みで遷移） |
| キーワード | 店舗名テキスト検索 |

### 明細テーブル

| 列 | 内容 | 備考 |
|---|---|---|
| 日付 | effective_date | 訂正済みは ✏️ マーク |
| 店舗名 | merchant_name | |
| 金額 | effective_amount | 訂正済みは ✏️ マーク |
| カテゴリ | セレクト即時変更 | Turbo Stream・未分類は強調 |
| 操作 | 編集・削除 | 削除は Turbo Stream で行を消す |

データなし時：
```
┌─────────────────────────────────────┐
│  2026年4月の明細                     │
│                                     │
│  まだデータがありません               │
│  [CSV を取り込む]                    │
└─────────────────────────────────────┘
```

## エラー時の画面遷移パターン

| エラー種別 | 発生場所 | 表示方法 | ユーザーアクション |
|---|---|---|---|
| CSV 形式エラー（パース失敗） | /imports/new | 同ページにインラインエラー表示（Turbo Stream） | ファイル選び直し |
| 重複ファイルエラー（同一 file_hash） | /imports/new | 同ページにエラー（「2026-01-07 に同じファイルを取り込み済みです」） | 取り込み履歴へのリンクを提示 |
| 手動まとめ入力バリデーションエラー | /imports/new | 該当行をハイライト + エラーメッセージ（Turbo Stream） | 入力修正して再送信 |
| 手動1件入力バリデーションエラー | /transactions/new | 同ページにインラインエラー表示 | 入力修正して再送信 |
| 明細編集バリデーションエラー | /transactions/:id/edit | 同ページにインラインエラー表示 | 入力修正して再送信 |
| 存在しないリソースへのアクセス | 全画面 | 404 ページ | トップへ戻る |
| 認証エラー（未ログイン） | 全画面 | /sign_in へリダイレクト | ログイン |

**基本方針**: エラーはページ遷移させず、フォームの近くに表示する（Turbo Stream / Rails バリデーション）。ただし重複ファイルのように「別の画面が正解」の場合はリンクで誘導する。

## 危険な操作の確認パターン

全ての破壊的操作に一貫した確認フローを適用する。

| 操作 | 確認方法 | 実装 |
|---|---|---|
| 明細の削除（1件） | ワンクリック確認（「本当に削除しますか？」フラッシュ） | Turbo Stream |
| Import の取り消し（まとめ） | 確認ページへ遷移（件数を明示。「この操作は取り消せません」） | 別ページ遷移 |
| 支払方法の削除（明細なし） | ワンクリック確認（「削除しますか？」） | Turbo Stream |
| 支払方法の削除（明細あり → アーカイブ） | モーダル確認（「過去 N 件の明細があるためアーカイブします。新しい入力では選択できなくなりますが、過去明細はそのまま残ります。」） | Turbo Stream |
| カテゴリの削除 | ワンクリック確認（削除後は明細が未分類になる旨を表示） | Turbo Stream |
| 退会 | 確認文字列の入力（`/account/delete`。「退会する」と入力して送信） | 別ページ遷移 |

**Turbo Stream 確認パターン（例: 明細削除）**
```
[削除] クリック
→ Turbo Stream で確認バナーを表示（「削除しますか？ [確定] [キャンセル]」）
→ [確定] クリックで POST /transactions/:id/destroy
→ 該当行が消える
→ [キャンセル] クリックで元の表示に戻る
```

- 予算ページの詳細設計（フェーズ2）
