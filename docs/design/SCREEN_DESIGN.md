# 画面設計

最終更新: 2026-04-11

---

## 技術方針

| 操作 | 実装方法 | 理由 |
|---|---|---|
| カテゴリ変更・明細削除・金額訂正 | Turbo Stream | JS不要・部分更新 |
| フォーム送信・ページ遷移 | Turbo Drive | 通常の Rails フォーム |
| 手動まとめ入力の行追加 | Stimulus | DOM 操作が必要な最小限の JS |
| グラフ描画・月切り替え | Stimulus + fetch + Chart.js | JSON を受け取って再描画 |

**基本方針**: Turbo Stream でページ遷移なしの部分更新を実現。JS は Stimulus + グラフのみに限定。

## 「取り込む」ボタンの配置

取り込み操作は `/imports/new` に集約するが、複数箇所からアクセスできる。

```
ダッシュボード   → [CSV取り込み] ボタン
明細一覧         → [CSV取り込み] ボタン（データがない月は特に目立つ）
グローバルナビ   → [+ 取り込み] 常設
```

---

## 入力経路

```
① CSV 取り込み（/imports/new）
   ファイル選択 → 支払方法選択 → 確認 → Import（source_type: csv）+ Transaction N件

② 手動まとめ入力（/imports/new）
   支払方法選択 → テーブル形式で複数件入力 → Import（source_type: manual_bulk）+ Transaction N件

③ 手動1件入力（/transactions/new）
   日付・金額・店舗名・支払方法・カテゴリ → Transaction 1件（import_id = NULL）
```

## 認証系

### ユーザー登録（/sign_up）

登録完了時に自動生成されるもの：
- 「現金」PaymentMethod（payment_type: cash）
- 初期カテゴリ（category_templates からコピー）

### アカウント設定（/account）

| 項目 | 内容 |
|---|---|
| メールアドレス変更 | |
| パスワード変更 | |
| 退会 | → /account/delete へ |

### 退会確認（/account/delete）

- 「退会するとすべてのデータが削除されます」という警告
- 確認文字列の入力を要求（誤操作防止）
- 実行 → users を CASCADE 削除

## ダッシュボード（/）

当月の収支サマリー。

```
┌─────────────────────────────────────┐
│  2026年4月の支出                     │
│  ¥128,400                           │
│                                     │
│  [カテゴリ別円グラフ]                 │← Stimulus + Chart.js
│                                     │
│  未分類 3件 ⚠️  → /transactions     │← 未分類バッジ（クリックで一覧へ）
│                                     │
│  [CSV 取り込み]  [手動入力]           │
└─────────────────────────────────────┘
```

グラフデータは `GET /transactions/summary?month=2026-04` → JSON で取得。

## 取り込み画面（/imports/new）

CSV 取り込みと手動まとめ入力をタブで切り替え。

### タブ1: CSV 取り込み

```
┌─────────────────────────────────────┐
│  [CSV 取り込み] [手動まとめ入力]      │
├─────────────────────────────────────┤
│  支払方法  [楽天カード ▼]            │
│  ファイル  [ファイルを選択]           │
│                                     │
│  ※同じファイルは取り込めません        │
│                                     │
│  [取り込む]                          │
└─────────────────────────────────────┘
```

取り込み後 → `/transactions`（当月）へ遷移。

### タブ2: 手動まとめ入力

```
┌─────────────────────────────────────┐
│  [CSV 取り込み] [手動まとめ入力]      │
├─────────────────────────────────────┤
│  支払方法  [現金 ▼]                 │
│                                     │
│  日付       店舗名       金額  カテゴリ│
│  [4/08] [ローソン    ]  [500] [食費▼]│
│  [4/09] [松屋        ]  [900] [食費▼]│
│  [4/10] [            ]  [   ] [  ▼ ]│
│  [+ 行を追加]            ← Stimulus  │
│                                     │
│  [保存]                              │
└─────────────────────────────────────┘
```

保存後 → `/transactions`（当月）へ遷移。

## 明細一覧（/transactions）

### 絞り込みバー

| 項目 | 内容 |
|---|---|
| 月 | 年月セレクト（デフォルト: 当月） |
| 支払方法 | セレクトボックス |
| カテゴリ | セレクトボックス |
| キーワード | 店舗名テキスト検索 |

### 明細テーブル

| 列 | 内容 | 備考 |
|---|---|---|
| 日付 | effective_date | 訂正済みは ✏️ マーク |
| 店舗名 | merchant_name | |
| 金額 | effective_amount | 訂正済みは ✏️ マーク |
| カテゴリ | セレクト即時変更 | Turbo Stream・未分類は強調 |
| 操作 | 編集・削除 | 削除は Turbo Stream で行を消す |

データなし時：
```
┌─────────────────────────────────────┐
│  2026年4月の明細                     │
│                                     │
│  まだデータがありません               │
│  [CSV を取り込む]                    │
└─────────────────────────────────────┘
```

## 明細編集（/transactions/:id/edit）

CSV 原本は変更不可。編集できる項目のみフォームを表示。

```
┌─────────────────────────────────────┐
│  明細の編集                          │
├─────────────────────────────────────┤
│  ── 原本（変更不可）──               │
│  日付    2026-03-31                 │
│  金額    ¥1,200                     │
│  摘要    ﾏｸﾄﾞﾅﾙﾄﾞ 新宿店            │
│                                     │
│  ── 編集できる項目 ──               │
│  店舗名    [マクドナルド        ]    │
│  カテゴリ  [食費 ▼]                 │
│  日付の訂正 [2026-04-01      ]      │← 空欄 = 原本を使用
│  金額の訂正 [                ]      │← 空欄 = 原本を使用
│                                     │
│  [保存]  [削除]                      │
└─────────────────────────────────────┘
```

## カテゴリ管理（/categories）

```
┌─────────────────────────────────────┐
│  カテゴリ                  [+ 追加]  │
├─────────────────────────────────────┤
│  食費      （初期）         [名前変更]│
│  交通費    （初期）         [名前変更]│
│  ─────────────────────────────────  │
│  外食費    （独自） [名前変更][削除]  │
└─────────────────────────────────────┘
```

- 初期カテゴリ：名前変更のみ・削除不可
- 独自カテゴリ：追加・名前変更・削除可

## 保留事項

- 手動まとめ入力の行数上限
- Import 取り消し時の確認フロー（件数が多い場合の警告）
- ダッシュボードのグラフ詳細（表示期間・集計単位）
- 予算ページの詳細設計（フェーズ2）
