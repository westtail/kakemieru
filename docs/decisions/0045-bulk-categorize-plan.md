# ADR-0045: 明細カテゴリの一括適用

- 日付: 2026-08-27
- ステータス: 承認（スコープ確定）
- 関連: [ADR-0044 明細ソート](0044-transaction-sort-plan.md) / #44 インラインカテゴリ変更
- 対象 Issue: #149

---

## コンテキスト

明細登録後のカテゴリ付けの手間を減らしたい。店舗名ソート（#147）で同じ店舗を並べ、複数明細を選択してまとめて1カテゴリを適用したい。自動分類は将来の別課題で、まずは手動一括で入力工数を下げる。

## 決定

- 明細一覧に**行チェックボックス + 全選択 + カテゴリ一括適用バー**を追加する。既存のインライン1件変更（`categorize`）は残す。
- **HTML5 の `form` 属性**で行チェックボックスを一括バーのフォームに紐づける。行内に既存のインラインカテゴリ変更 `<form>` があり、テーブル全体を form で包むと入れ子になるため、包まずに `form="..."` で関連づける。
- 新エンドポイント **`PATCH /transactions/categorize_all`**（collection ルート）:
  - `transaction_ids[]`（選択 ID）と `category_id`（未分類は空）を受け取る。
  - **テナントスコープ**: `Current.user.transactions.not_deleted.where(id: ids)` のみ更新（他人の ID は一致せず無視）。
  - **カテゴリ所有チェック**: `category_id` は空 or `Current.user.categories` に属することを確認。不正なら alert で戻す。
  - `update_all(category_id: ...)` で一括更新（バリデーションは通らないが、テナント整合は上記スコープ + 所有チェック + DB 複合FK #113 で担保）。
  - 現在の絞り込み/ソート（month/category/q/sort/direction）を維持して一覧へ **redirect**（正しく再描画・再ソート）。件数を notice。
- **Stimulus `bulk-categorize`**: 全選択トグル、選択件数表示、選択0のとき適用ボタンを無効化。

## スコープ外

- 「同じ店舗すべてに一発適用」ショートカット（全選択で代替可・将来）。
- 自動カテゴリ分類（別課題）。一括削除など他の一括操作。
