# ADR-0050: ビジュアルデザイン指針「家計簿ノート」の採用

- ステータス: 承認済み
- 関連: #172（ランディングページ）、[ADR-0049](0049-landing-page-plan.md)、[ADR-0043](0043-ui-component-classes-plan.md)（共通UIコンポーネントクラス）

---

## 背景

これまでの画面は Tailwind の既定に近い青基調の汎用SaaS風で、[ADR-0043](0043-ui-component-classes-plan.md) で共通コンポーネントクラス（`btn-primary` 等）を整えたものの、プロダクト固有の個性・世界観が無かった。ランディングページ（#172）を機に複数のデザイン方向を比較検討し、題材（クレジットカード明細 → 家計簿）に根ざした指針を1つ選定してアプリ全体で一貫させることにした。

比較した方向: 家計簿ノート（紙・インク紺・朱印）／ダークなデータ・コックピット／和文ミニマル（明朝）／フレンドリー丸ゴシック。

## 決定

ビジュアル指針として **「家計簿ノート」** を採用する。

- **世界観**: 手元の帳簿のような温かみ（紙の地色）と、数字への信頼感（インク紺＋等幅数字）。朱印をブランドアクセントに使う。
- **採用した組み合わせ（比較検討の結論）**:
  - 全体トーン＝家計簿ノート（インク紺＋朱印・紙地・レシート/ノート風・ノート系アイコン）。ただし**方眼（網目）の背景は使わない**（可読性優先・紙の地色のみ）。
  - 読みやすさ＝フレンドリー案由来（**中央寄せの見出し・広い余白・適度な丸み・ソフトな影・ステップの円**）。
  - フォントは**角ゴシック**（Zen Kaku Gothic New）を正とし、丸ゴシックは採用しない。
  - ヒーロー等の主役ビジュアルは**ノート風ミニダッシュボード**（支出合計＋グラフ＋主要カテゴリ）。グラフは **カテゴリ別ドーナツ** を標準採用する（棒＝月別推移は従として併用可）。
- **一次ボタン**はインク紺の塗り、朱は印・下線・アイコン・強調に限定して効かせる。
- 具体のトークン（色・タイポ・余白・角丸・影）とコンポーネント定義は [docs/design/DESIGN_SYSTEM.md](../design/DESIGN_SYSTEM.md) に置き、本ADRは「どの方向を選んだか」の意思決定を記録する。

### 適用範囲と段階

- **先行**: ランディングページ（#172）で本指針を初適用する。
- **順次**: 既存画面の共通クラス（`btn-primary` 等）の配色をインク／朱へ移行し、ダッシュボードのグラフ配色も本指針のカテゴリ配色に揃える。[ADR-0043](0043-ui-component-classes-plan.md) のクラス体系は維持し、色・影・角丸・新規コンポーネント（ミニダッシュボード、バッジ等）を本指針で拡張する。

## 非スコープ

- 独自ドメイン・OGP・SEO・ロゴの作り込み（朱印は暫定のCSS表現）。
- ダークモードの全画面対応（トークンは両テーマを想定して定義するが、全画面適用は段階的）。
- 既存全画面の一括リデザイン（破壊的変更を避け、共通クラス経由で順次移行する）。
